## 设计和交互修复

| 问题 | 修复 |
| --- | --- |
| 手机保存按钮外出现独立黑色矩形 | 移除异色吸底背景，保存操作与面板保持同一背景，只保留上方分隔线；空提示不占一行 |
| 手机顶栏、配置菜单透出下面的文字和图片 | 使用实色主题背景，去掉叠加模糊；保留原抽屉导航 |
| 纯色模式的全局按钮阴影覆盖了菜单、头像和压缩卡片样式 | 阴影移到普通按钮基础样式，各控件可正常覆盖 |
| 部分主按钮白字对比度不足 | 深色纯色主按钮调整为更深的紫色，白字对比度约 4.95:1；渐变按钮改用深色文字，危险按钮使用深红底白字 |
| 无限滚动时旧图片被 CSS 多列重新分配，阅读位置跳动 | 根据已知宽高分配到固定瀑布流列；追加数据不再改变旧图片所在列 |
| 键盘难以使用图片和文件选择控件 | 加入焦点轮廓、图片 Enter/Space 打开、文件选择键盘入口、表单标签关联；支持减少动画的系统偏好 |
| 从长页面切换页面后停在中间 | 页面切换回到顶部；后台内部切换栏目保持菜单可用 |
| 保存空数字只出现内部配置键错误 | 保存前显示字段名称和有效数字提示；有草稿时显示未保存状态 |
| 通知测试使用旧的已保存配置，容易误判新配置 | 通知有修改时提示先保存并暂停测试按钮，保存后可发送 |

## 功能和可靠性修复

- 错误的旧密码只显示操作错误，不再把有效会话当成过期并退出登录。
- 登录验证有明确的等待状态；旧登录请求的迟到响应不能覆盖新会话，退出后也不会被迟到请求重新登录。
- 随机图公开后，其页面也允许游客使用；网络错误与没有图片分别显示，避免多个随机请求相互覆盖结果。
- 后台按栏目加载数据，首页不再自动扫描本地文件、补压缩列表和所有统计；加载失败有可见提示。
- 用户创建/更新保留成功反馈并防止重复提交；更新自身身份后刷新权限；管理员配额显示与后端的“不受业务上传限制”规则一致。
- 导入完成/失败提示不会被随后扫描覆盖；导入任务运行时恢复返回明确的忙碌提示，避免阻塞整个站点等待导入结束。
- 内部导入失败队列、通知发送日期不会传入设置表单，避免队列较大时整个设置保存请求超过大小上限。
- Webhook JSON 模板正确处理多行文本、引号和结构化 `{{fields}}`；无效 JSON 给出明确错误。
- 重命名写库成功后，即使客户端断开也不回滚已经提交的文件；恢复回滚如遇文件系统错误，保留恢复暂存数据并记录位置。
- ZIP 展开大小检查避免整数溢出；损坏数据库归档在切换前拒绝。
- 上传条目改为响应式对象，修复进度和状态更新不及时；GIF 不显示不存在的压缩版复制入口；复制失败不再提示成功。
